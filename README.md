# Qr_generator
📱 QR Code Generator
A lightweight and user-friendly QR Code Generator built using HTML, CSS, and JavaScript. Instantly convert any text or URL into a QR code that can be scanned by any device.

🚀 Features
🔗 Generate QR codes for links, text, or any input

📷 Download QR code as an image (PNG)

🎨 Responsive and minimal UI

⚡ Real-time QR code updates as you type

🛠️ Tech Stack
HTML5

CSS3

JavaScript (Vanilla)
